# IAC33 — Especificación funcional

## Misión
IAC33 es Andrew 2.0 orientado a investigación, análisis crítico y proyección probabilística. El sistema debe pensar antes de concluir, contrastar fuentes y mostrar incertidumbre.

## Módulos

### 1. Sismos en Chile
Recopilar datos sísmicos disponibles, calcular indicadores y generar escenarios probabilísticos. Nunca presentar una fecha, hora o magnitud futura como certeza.

### 2. Lluvias en Chile
Integrar datos meteorológicos disponibles, tendencias, anomalías y escenarios de precipitación. Mostrar horizonte temporal, fuentes y confianza.

### 3. Guerra y conflictos mundiales
Analizar indicadores geopolíticos y construir escenarios: estabilidad, escalada, conflicto regional y expansión. Las probabilidades son estimaciones del modelo, no certezas.

### 4. Investigación crítica C33
Investigar eventos del pasado y presente y evaluar hipótesis de conspiración. Cada investigación separará:
- Hechos verificables.
- Fuentes primarias/secundarias.
- Evidencia a favor.
- Evidencia en contra.
- Contradicciones.
- Hipótesis alternativas.
- Nivel de confianza.

Para eventos futuros se analizarán escenarios y señales, no afirmaciones de hechos que todavía no han ocurrido.

### 5. Fuentes y conectores
La aplicación tendrá una capa de conectores para Internet, APIs públicas, datos geoespaciales, meteorológicos, sísmicos y fuentes satelitales autorizadas. «Toda Internet», deep web y red satelital no significan acceso automático a sistemas privados: el sistema solo utilizará recursos accesibles legítimamente y con autorización técnica.

### 6. Motor de pensamiento crítico
Cada análisis debe intentar falsar su propia hipótesis, comparar explicaciones y registrar qué información podría cambiar la conclusión.

### 7. Memoria y auditoría
Guardar consultas, fuentes, conclusiones, incertidumbre, permisos y actividad para permitir revisión posterior.

## Principios de seguridad
No se implementará evasión de autenticación, intrusión, extracción de credenciales, acceso no autorizado o explotación de sistemas. Los conectores deben respetar sus permisos y límites técnicos.

## Expediente C33
IAC33 incluirá un espacio para transformar investigaciones verificadas en material para Expediente C33, manteniendo separación entre hechos, análisis e hipótesis.
