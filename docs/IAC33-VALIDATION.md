# IAC33 — Validación técnica

## Objetivo

Validar de forma repetible el núcleo de IAC33 antes de ampliar sus módulos de análisis.

## Orden

1. TypeScript/typecheck.
2. Build de producción.
3. Pruebas automatizadas.
4. Corrección de errores.
5. Nueva validación completa.

## Regla

No marcar IAC33 como estable basándose solo en commits. La versión estable requiere una ejecución real de typecheck, build y tests en un entorno de ejecución.

## Aprendizaje

El motor de aprendizaje debe conservar trazabilidad del resultado, confianza, lección generada y proyecto asociado. Las escrituras de memoria deben permanecer protegidas por autorización.

## Próximo bloque

Conectar y validar los resultados de los módulos de sismos, lluvias y conflictos con el ciclo de aprendizaje, sin convertir probabilidades en predicciones deterministas.
